# ADR 0014: Inside the operations package, submodules import siblings by path, never the façade

- forbid_pattern: `^from torsor_helper\.operations import` in `src/torsor_helper/operations/*.py` — a submodule must import siblings by full path (from torsor_helper.operations.memory import x), never the package facade (ADR 0014) — the facade is half-initialised while the package is loading
- forbid_pattern: `^from \. import` in `src/torsor_helper/operations/*.py` — same as above (ADR 0014): `from . import x` inside operations/ re-enters the package facade during init
